# roarway-game

3D models and sounds for **ROARWAY**, a free jungle escape running game on vinish.dev. The game loads these files from `public/`.

| File | What it is | Source and licence |
|---|---|---|
| `explorer.glb` | The explorer you play, with run, jump, slide, stumble and fall clips | Character and animations from Adobe Mixamo, converted and trimmed for the game. Used under the Mixamo terms; not for reuse as standalone assets. |
| `driver.glb` | The jeep driver | Adobe Mixamo, as above |
| `elephant.glb` | Elephant (walk, idle, trumpet) | [Elephant](https://sketchfab.com/3d-models/elephant-4ae161372d6a4219a87340339d1ffe03) by Rukh3D, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `giraffe.glb` | Giraffe (walk, idle) | [Giraffe](https://sketchfab.com/3d-models/giraffe-2f389c12391f422e966c7f63b7813d31) by planeta-elefante, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `zebra.glb` | Zebra (gallop, walk) | [Zebra](https://sketchfab.com/3d-models/zebra-98011fb6420246b0b2ddf56170316871) by planeta-elefante, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `rhino.glb` | Rhino (walk) | [Rhino Animation Walk](https://sketchfab.com/3d-models/rhino-animation-walk-a915d9179fe6422b9d669a3a0d726b8e) by GremorySaiyan, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `lion.glb` | Lion (run, leap, roar, bite) | [Lion](https://sketchfab.com/3d-models/lion-e5adb6265b944c5990031a9aa93ee316) by planeta-elefante, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `cheetah.glb` | Cheetah (run, leap, snarl, swipe) | [Cheetah](https://sketchfab.com/3d-models/cheetah-8d3ba32a2ff34acc9b5c590bc06cb561) by planeta-elefante, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

Changes made for the game: unused animations removed, textures resized to 512 px WebP, meshes compressed with meshopt, and (rhino) slightly simplified.

## Sounds

`snd/` holds the game's sounds: `sfx.mp3` (one-shot sprite), `music.mp3`, `engine.mp3` and three ambience loops. They are cut, levelled and looped from CC0 (public domain) recordings on [Freesound](https://freesound.org/).
